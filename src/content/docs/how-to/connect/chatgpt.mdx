A sign-in code is a one-time code that lets one app connect. It works once, for one connection, and expires unused after 24 hours. Connecting ChatGPT and Claude takes two codes, and reconnecting later takes a new one.

## Add the server

Custom MCP servers are added in ChatGPT on the web. Menu names change, so look for them rather than expecting these exact words.

<Steps>

1. In ChatGPT on the web, look for **Plugins** (or a similar place for custom MCP servers).
2. Create a new one. Give it a name such as `Telekin`, an optional description, and paste your **Server URL**.
3. For authentication, choose **OAuth** (a way of signing in through a page in your browser; there's no password to paste). Leave any client ID or client secret fields empty.
4. Create it, then install it.
5. ChatGPT opens Telekin's sign-in page in your browser. It names the app that's connecting. Type your sign-in code and choose **Continue**.
6. The next page states what will be granted: read or write access, which memory (catalog), and the name your changes are recorded under. Choose **Approve**. Your browser returns to ChatGPT, now connected. (**Deny** leaves your code unused.)

</Steps>

Finish the sign-in within 10 minutes of the page opening, and don't mistype the code five times, or it ends and you start again from ChatGPT. Once connected, ChatGPT stays connected on its own as long as you use it regularly.

Two things may get in your way. Which ChatGPT plans include custom MCP servers isn't confirmed, and if you're in a workspace, an admin can restrict adding them.

## Check it works

In a new chat, ask: **"What tools do you have from Telekin?"** You should see ChatGPT list tools for searching and saving to your memory. Then ask **"What do you know about me?"**; on an empty memory it will tell you there's nothing yet.

ChatGPT asks for your confirmation before each change it makes to your memory. That is expected. Approve the ones you want.

If it won't connect, check that the URL ends in `/mcp`. If the sign-in page says your code didn't work, see [Troubleshoot](/how-to/guides/troubleshoot/).

## Undo it

Remove the Telekin server from the same place in ChatGPT where you added it. Nothing is deleted from your memory; it just stops being connected to ChatGPT. The person running your Telekin server can also revoke the connection. To connect again later, you'll need a new sign-in code.
