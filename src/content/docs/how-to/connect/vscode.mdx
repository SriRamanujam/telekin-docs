VS Code has two ways to describe MCP servers, and newer Copilot setups also read separate files of their own. This page uses VS Code's own `mcp.json` file, because it can ask you for your key and store it securely instead of leaving it in the file.

## Add the server

VS Code reads servers from a file called `mcp.json`. There are two places for it:

- `.vscode/mcp.json` inside a project is the **workspace** file: the server is available only in that project.
- The `mcp.json` in your **user profile** is available in every project.

<Steps>

1. Create or edit one of those files so it contains this, with your own server URL. If the file already has other servers, add the `"telekin"` entry inside `servers` and the key prompt inside `inputs`.

   ```json
   {
     "inputs": [
       {
         "type": "promptString",
         "id": "telekin-key",
         "description": "Telekin key",
         "password": true
       }
     ],
     "servers": {
       "telekin": {
         "type": "http",
         "url": "<server URL>",
         "headers": {
           "Authorization": "Bearer ${input:telekin-key}"
         }
       }
     }
   }
   ```

2. Start the server from the file. VS Code usually shows a Start control above the server entry in the file. The first time it starts, VS Code asks for the value of `telekin-key`. Enter `<your key>` alone, without the word `Bearer`: the file already adds it. VS Code stores it for next time. If nothing asks for your key, reload the window.

</Steps>

If you would rather paste the key into the file, replace the value `Bearer ${input:telekin-key}` with `Bearer <your key>` and delete the `inputs` section. Then don't commit that file to a shared repository.

You can also run **MCP: Add Server** from the Command Palette, choose the HTTP option and enter the URL. That flow doesn't ask for a header, so you'd still edit the JSON afterwards to add the `headers` section.

Organization settings can restrict MCP access in VS Code. If you can't add the server, ask whoever manages your Copilot.

## Check it works

Open Copilot chat in agent mode and ask: **"What tools do you have from Telekin?"** You should see a list. Then ask **"What do you know about me?"**; on an empty memory it will say there's nothing yet. VS Code asks you to approve each tool call, so approve the request when it appears.

If it won't connect, check that the URL ends in `/mcp` and that the key you entered is only the key.

## Undo it

Delete the `"telekin"` entry (and the `telekin-key` input) from the `mcp.json` file you edited.
