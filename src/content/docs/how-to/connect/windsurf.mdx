## Add the server

Windsurf keeps its servers in a file called `mcp_config.json`. Its docs name more than one location for that file, so don't go looking for it by path. Let Windsurf open the right one for you.

<Steps>

1. In Windsurf's Cascade panel, open the MCP menu and choose **Open MCP config file**. (Alternatively, go to **Settings, then Tools, then Windsurf Settings**, and use **Add Server**.)
2. Make the file contain this, with your own server URL and key. If it already has other servers, add only the `"telekin"` entry inside `mcpServers`.

   ```json
   {
     "mcpServers": {
       "telekin": {
         "serverUrl": "<server URL>",
         "headers": {
           "Authorization": "Bearer <your key>"
         }
       }
     }
   }
   ```

3. Save the file, then press the refresh button in the MCP menu so Cascade picks up the change.

</Steps>

Windsurf's docs show `headers` with a different example header name, not `Authorization`, so `Authorization` should work here but we haven't seen it written out there. If the server doesn't connect, <a href={CONTACT_URL}>tell us</a>.

On Enterprise, MCP has to be turned on in settings. On a team, admins can turn MCP on or off and limit which servers are allowed.

## Check it works

In a Cascade chat, ask: **"What tools do you have from Telekin?"** You should see a list. Then ask **"What do you know about me?"**; on an empty memory it will say there's nothing yet.

If it won't connect, check that the URL ends in `/mcp` and that the header value starts with `Bearer ` (with a space).

## Undo it

Use **Open MCP config file** again, delete the `"telekin"` entry, save, and press refresh.
