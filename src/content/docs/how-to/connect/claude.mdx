You'll need: your server URL and a sign-in code (from your invite).

A sign-in code is a one-time code that lets one app connect. It works once, for one connection, and expires unused after 24 hours. Connecting Claude and ChatGPT takes two codes, and reconnecting later takes a new one. If you need another, ask whoever gave you your invite.

## Add the connector

<Steps>

1. Go to **Customize, then Connectors** (claude.ai/customize/connectors).
2. Click **+ Add**, then **Add custom connector**.
3. Name it `Telekin`, paste the **Server URL**, and click **Continue**. If you're asked how to authenticate, choose **OAuth**. Leave any client ID or client secret fields empty.
4. Claude opens Telekin's sign-in page in your browser. It names the app that's connecting. Type your sign-in code and choose **Continue**.
5. The next page states what will be granted: read or write access, which memory (catalog), and the name your changes are recorded under. Choose **Approve**. Your browser returns to Claude, now connected. (**Deny** leaves your code unused.)
6. In a chat, click **+**, then **Connectors**, and make sure `Telekin` is on.

</Steps>

Finish the sign-in within 10 minutes of the page opening, and don't mistype the code five times, or it ends and you start again from Claude. Claude Desktop uses the same connectors and the same settings page.

A few things worth knowing:

- Free plans allow one custom connector.
- Once connected, Claude stays connected on its own as long as you use it regularly.
- On Team and Enterprise plans, a connector an owner adds to the organization connects everyone through one sign-in, so everyone would see and change the same memory. Don't add Telekin that way. Add it as your own connector instead. Telekin is for one person per memory today; teams are planned.
- Claude connects from Anthropic's servers, so the server URL must be reachable from the public internet.

**On your phone:** connectors you add on the web or desktop should appear in the Claude mobile apps after you next sign in. Set it up on the web or desktop first.

## Check it works

In a chat with `Telekin` switched on, ask: **"What tools do you have from Telekin?"** You should see Claude list tools for searching and saving to your memory. Then ask **"What do you know about me?"**; on an empty memory it will tell you there's nothing yet.

If the connector won't connect, check that the URL ends in `/mcp`. If the sign-in page says your code didn't work, see [Troubleshoot](/how-to/guides/troubleshoot/). If Claude says it has no tools, make sure the connector is toggled on in this chat (**+**, then **Connectors**).

## Undo it

Go to **Customize, then Connectors**, open `Telekin` and remove it. Nothing is deleted from your memory; it just stops being connected to Claude. The person running your Telekin server can also revoke the connection. To connect again later, you'll need a new sign-in code.
