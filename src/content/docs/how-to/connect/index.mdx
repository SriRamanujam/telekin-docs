One short guide per AI app, each showing how to connect that app to your memory. Pick the app you use and follow the numbered steps.

Two kinds of credential are in your invite. A **key** is for developer tools (Claude Code, Cursor, VS Code and the like). A **sign-in code** is for apps that only accept OAuth sign-in: Claude on the web and desktop, and ChatGPT. A sign-in code works once, for one connection, and expires unused after 24 hours.

| App | Uses | Status | Guide |
| --- | --- | --- | --- |
| Claude (web and desktop; mobile apps should follow) | Sign-in code | Works today | [Connect Claude](/how-to/connect/claude/) |
| Claude Code | Key | Works today | [Connect Claude Code](/how-to/connect/claude-code/), or [enhanced](/how-to/connect/claude-code-enhanced/) |
| Cursor | Key | Works today | [Connect Cursor](/how-to/connect/cursor/) |
| VS Code (GitHub Copilot) | Key | Works today | [Connect VS Code](/how-to/connect/vscode/) |
| Windsurf | Key | Works today | [Connect Windsurf](/how-to/connect/windsurf/) |
| OpenAI Codex CLI | Key | Works today | [Connect Codex CLI](/how-to/connect/codex-cli/) |
| Gemini CLI | Key | Works today | [Connect Gemini CLI](/how-to/connect/gemini-cli/) |
| Cline | Key | Works today | [Connect Cline](/how-to/connect/cline/) |
| ChatGPT | Sign-in code | Works today | [Connect ChatGPT](/how-to/connect/chatgpt/) |
| Any other app | Either | Maybe | [What an app needs](/how-to/connect/any-mcp-client/) |
